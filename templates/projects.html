A two-way Morse En- & Decoder

Morse En- & Decoder is a web-based tool that lets you easily convert regular text to Morse code — and vice versa! Type a message to have it played back as sound, or analyze a recorded Morse pattern to get the decoded text. The website is built with Flask (Python) and combines modern web technologies like HTML, CSS, and JavaScript for a smooth user interface.

Several powerful Python libraries are used behind the scenes: Flask for the web framework, WTForms for secure web forms, and Simpleaudio for sound playback. For handling sound recording and analysis, the project uses SoundDevice, SoundFile, and NumPy for audio operations and array processing; SciPy and Librosa to generate and visualize spectrograms; and Matplotlib for plotting.

Text to Morse: This feature generates and plays audio files mapped to each character's Morse code.
Morse to Text: You can record sounds; the backend creates a spectrogram using these audio and plotting libraries, then processes the image to interpret the Morse patterns back to text.

In this way, Morse En- & Decoder becomes a fun and educational tool for anyone who wants to experiment with Morse code!
